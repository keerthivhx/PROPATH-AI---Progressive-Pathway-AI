# ProPath AI

> AI-powered career guidance platform built with React, Node.js, MongoDB, and Qwen3 (via Ollama)

## 🚀 Features

| Feature | Description |
|---------|-------------|
| 🧠 AI Domain Assessment | 10 adaptive questions — Qwen analyzes each answer to generate the next |
| 🗺️ 4-Year Roadmap | Personalized career roadmap generated by Qwen |
| 💻 Learning Tasks | Code editor (11 languages) with AI validation |
| 🎤 AI Interview | Voice + text, adaptive questions, multi-language, real-time evaluation |
| 💼 Projects | Submit projects, AI validates code quality |
| 📋 JD Validator | AI extracts and validates job descriptions |
| 🚀 Portfolio | Showcase skills, projects, and interview results |
| 💬 AI Chat | General Qwen-powered career assistant |

## 🛠️ Setup

### Prerequisites
- Node.js 18+
- MongoDB (local or Atlas)
- [Ollama](https://ollama.com) installed and running

### 1. Pull the AI model
```bash
ollama pull qwen3:4b
ollama serve
```

### 2. Configure backend
Edit `backend/.env`:
```
PORT=5000
MONGO_URI=mongodb://localhost:27017/propath
JWT_SECRET=your_secret_key
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=qwen3:4b
```

### 3. Start the app
**Windows:**
```
double-click start.bat
```

**Manual:**
```bash
# Terminal 1 — Backend
cd backend
node server.js

# Terminal 2 — Frontend  
cd frontend
npm run dev
```

### 4. Open in browser
```
http://localhost:5173
```

## 🤖 AI Architecture

All AI features use **Qwen3:4b** via **Ollama** (local, no API key needed):

- **Assessment**: Qwen generates adaptive questions from full Q&A history
- **Roadmap**: Qwen creates domain-specific 4-year learning plans
- **Interview**: Qwen asks adaptive technical questions + evaluates answers
- **Task Validation**: Qwen reviews code correctness and quality
- **Project Validation**: Qwen performs code review and quality scoring
- **JD Validation**: Qwen extracts and validates job description content
- **Chatbot**: Qwen answers general career and tech questions
